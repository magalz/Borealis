# 0030 Use kotlinx.serialization

## Context and Problem Statement

Which serialization library should new Kotlin code use for JSON, for example for the LuminalShine REST API?

## Considered Options

* kotlinx.serialization
* Moshi
* Gson (as Artemis)
* org.json

## Decision Outcome

Chosen option: "kotlinx.serialization", because it uses no reflection and its code is generated by the compiler. The trade-off is that it works only with Kotlin.

### Consequences

* Good, because it uses no reflection, and the code is generated by the compiler.
* Bad, because it works only with Kotlin.

## Pros and Cons of the Options

### kotlinx.serialization

* Good, because it uses no reflection, and the code is generated by the compiler.
* Bad, because it works only with Kotlin.

### Moshi

* Good, because it is mature.
* Bad, because it needs KSP or reflection.

### Gson (as Artemis)

* Good, because it is well known.
* Bad, because it uses reflection and has no null-safety.

### org.json

* Good, because it is built into Android.
* Bad, because parsing is manual and fragile.
